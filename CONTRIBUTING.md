## Developer Certificate of Origin (DCO)

Cada commit debe llevar una línea `Signed-off-by` con tu nombre y email reales:

```
Signed-off-by: Nombre Apellido <tu@email.com>
```

Se agrega sola con `git commit -s`. Con ella certificas el [Developer Certificate of Origin 1.1](https://developercertificate.org/): que escribiste el cambio o tienes derecho a aportarlo bajo la licencia del proyecto.

No hay CLA: conservas el copyright de tu aporte.
